# Contributing

All help is welcome: bug reports, ideas, typo fixes, art, code, or just telling us what confused you.

## Quick ways to help
- **Found a bug or something hard to read or use?** Open an issue and say what you did, what you expected, and what happened. A screenshot helps.
- **Have an idea?** Open an issue with it. Small, silly ideas are welcome.
- **Want to change code?** Fork the repo, make your change on a branch, and open a pull request.

## Running it locally
- `npm install` then `npm run dev`, and open http://localhost:8787 (open two tabs to see multiplayer).
- The game is one page, `public/index.html`, plus the world server in `src/worker.js`.

## Accessibility
Please keep the game playable for everyone: it should work with touch, mouse, and keyboard; text should stay on screen long enough to read; and motion like screen shake should stay off when "reduce motion" is turned on.

Be kind. This project roasts unfinished code, never people.
